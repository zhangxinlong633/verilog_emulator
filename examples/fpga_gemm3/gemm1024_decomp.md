# 1024×1024 分块（ASIC 风格叶引擎）

产品定档叶尺寸 **T=64**（~12 亿管、die ≈ 2 cm²）；仓库可仿真最大叶为 T=32。

| | T=32 | T=64（定档） |
|--|-----:|-----:|
| NT = 1024/T | 32 | **16** |
| 叶调用（单叶串行） | 32768 | **4096** |
| 约拍数 `NT²·(2+4·NT)` | 133120 | **16896** |
| @500 MHz | ≈ 266 µs | ≈ **34 µs** |
| @1 GHz | ≈ 133 µs | ≈ **17 µs** |
| 约晶体管 | ~150 M | ~**1.2 B** |

## N=1024 → T=64 怎么展开

1. 切成 **16×16** 个 **64×64** 块（`ti,tj,tk ∈ 0…15`）。  
2. `C[ti][tj] += A[ti][tk] · B[tk][tj]`，每个输出块沿 k 累加 16 次。  
3. 可选：内存先按 64×64 **预分块**，再 tiling（带宽更友好）。  
4. 单叶串行 ≈ 4096 次叶调用；并行分解则只扫 16 层 k（见 README 1.2.2 / 1.2.4）。
