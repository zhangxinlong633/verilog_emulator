# vs P0 Parser + AST Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the `vs` CLI that lexes/parses the v0.1 Verilog subset with flex+bison, builds an arena AST, and dumps tokens/AST with golden tests.

**Architecture:** QEMU-like stages; P0 is frontend only. Reentrant flex scanner + pure bison parser build `vs_design_t` via `vs_parse_ctx_t`. Utilities (`arena`, `strtab`, `diag`) are independent. CLI prints dumps to stdout and diagnostics to stderr.

**Tech Stack:** C11, CMake ≥ 3.16, flex ≥ 2.6, **bison ≥ 3.0** (macOS system bison 2.3 is insufficient — use Homebrew `bison`), CTest.

## Global Constraints

- Program name: **`vs`** (not `ve_parse`)
- Language: pure **C11** (no C++ in tree)
- Frontend: **flex + bison**; generated `lex.yy.c` / `parse.tab.*` stay in the **build/** tree only
- bison minimum: **3.0+** with `api.pure full`; on macOS install `brew install bison` and point CMake at `/opt/homebrew/opt/bison` (or `/usr/local/opt/bison`)
- Exit codes: **0** success, **1** lex/parse errors, **2** usage/IO
- AST dump: deterministic text, **no** absolute paths or pointer addresses
- Spec / docs: `docs/superpowers/specs/2026-09-17-verilog-emulator-design.md`, `docs/grammar-v0.1.md`, `docs/ast.md`
- TDD: for each grammar slice, add `tests/parse/ok|fail` first (or same commit as feature), then implement until green
- Commit after each task

        "  -V, --version    Show version\n");
}

int main(int argc, char **argv) {
    int dump_ast = 0, dump_tokens = 0;
    int file_count = 0;
    char **files = NULL;

    for (int i = 1; i < argc; i++) {
        if (!strcmp(argv[i], "-h") || !strcmp(argv[i], "--help")) {
            usage(stdout);
            return 0;
        }
        if (!strcmp(argv[i], "-V") || !strcmp(argv[i], "--version")) {
            puts("vs 0.0.0-p0");
            return 0;
        }
        if (!strcmp(argv[i], "--dump-ast")) { dump_ast = 1; continue; }
        if (!strcmp(argv[i], "--dump-tokens")) { dump_tokens = 1; continue; }
        if (argv[i][0] == '-') {
            fprintf(stderr, "vs: unknown option %s\n", argv[i]);
            usage(stderr);
            return 2;
        }
        /* collect later; for now require at least tracking */
        (void)dump_ast; (void)dump_tokens;
        file_count++;
        files = &argv[i];
        /* simplify: remember first file index */
        break;
    }

    /* Re-scan properly in Task 4+; for Task 1 allow no files for help/version only */
    if (argc == 1) {
        usage(stderr);
        return 2;
    }

    /* If user passed only unknown dump flags without files, still 2 until parser exists */
    (void)file_count;
    (void)files;
    fprintf(stderr, "vs: parsing not implemented yet\n");
    return 2;
}
